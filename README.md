# ميثاق 🌙

تطبيق خاص لشخصين فقط — لتنظيم مواعيد العلاقة الزوجية بطريقة ممتعة وملتزمة، بهوية «ليل النجوم» العربية.

## الميزات

- **📅 المواعيد** — اقتراح، تأكيد، اقتراح وقت بديل، وتحصيل بعد الموعد («تم الموعد؟») مع احتفال عند الإتمام
- **🌙 إشارة المزاج** — زر سري يعبر فيه أي طرف عن رغبته، يظهر للآخر فورًا بثلاث ردود، وعند التطابق يُعتمد موعد الليلة بضغطة
- **🎮 صالة ألعاب ثنائية مباشرة** (كل واحد من جواله بمزامنة فورية):
  - إكس-أو
  - حجرة ورقة مقص (اختيار سري وكشف متزامن — أفضل من ٣)
  - من منا؟ (١٠ أسئلة وكشف التطابق)
  - بطاقات صارحني / تحدي (٤٠ بطاقة عربية)
- **🏆 رهانات الألعاب** — الفائز يقرر الموعد القادم (يُعتمد تلقائيًا) أو يسجل أمنية والخاسر ملزم يحققها (صفحة أماني خاصة)
- **🎡 عجلة العقاب** — من يخلف الموعد يدور عجلة عقوبات متفق عليها، مع زر «مسامح/ة 💝»
- **⭐ التحفيز** — نقاط ثنائية مشتركة، سلسلة التزام 🔥، مستويات بألقاب عربية، ٩ أوسمة، وتحدي شهري بجايزة
- **🔒 الخصوصية** — قفل PIN محلي، اسم وأيقونة محايدة، بياناتكم محمية بقواعد Firestore لأعضاء الميثاق فقط

## التشغيل

```bash
npm install
npm run dev
```

### الوضع التجريبي (بدون Firebase)

لمعاينة التطبيق ببيانات وهمية:

```bash
VITE_DEMO=1 npm run dev
```

### الربط بـ Firebase (مطلوب للاستخدام الفعلي)

1. أنشئ مشروعًا في [console.firebase.google.com](https://console.firebase.google.com)
2. فعّل **Authentication → Sign-in method → Email/Password**
3. فعّل **Cloud Firestore** (وضع الإنتاج)
4. من **Firestore → Rules** الصق محتوى ملف [`firestore.rules`](firestore.rules) وانشره
5. من **Project settings → Your apps** أنشئ تطبيق ويب `</>` وانسخ القيم
6. انسخ `.env.example` إلى `.env` واملأ القيم
7. `npm run dev` — وسجلوا حسابين (واحد لكل طرف) واربطوهما بكود الدعوة

## النشر (Firebase Hosting)

```bash
npm run build
npx firebase-tools login
npx firebase-tools use <project-id>
npx firebase-tools deploy --only hosting,firestore:rules
```

بعد النشر افتحوا الرابط من جوالاتكم واختاروا **إضافة إلى الشاشة الرئيسية** — يتثبت كتطبيق PWA كامل.
